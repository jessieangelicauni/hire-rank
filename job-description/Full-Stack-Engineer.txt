Full-Stack Engineer
We are a fast-growing fintech startup looking for a Full-Stack Engineer who can move comfortably between frontend and backend work. You'll own features end-to-end, from database schema to the final UI polish.

Requirements:
- Proficiency in TypeScript across both React or Next.js (frontend) and Node.js (backend, Express or NestJS).
- Experience designing and consuming REST APIs.
- Working knowledge of PostgreSQL and ORMs such as Prisma.
- Comfortable with Git-based workflows and code review.
- A pragmatic, product-minded approach to engineering trade-offs.

Nice to have (not required, but a plus):
- Familiarity with Docker for containerized development and deployment.
- Some exposure to deploying applications to a cloud platform such as AWS or GCP.
- Familiarity with CI/CD pipelines (GitHub Actions).
- Experience with Stripe payment integrations and Kubernetes.
