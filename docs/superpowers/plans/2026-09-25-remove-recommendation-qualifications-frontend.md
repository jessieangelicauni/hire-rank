# Remove Recommendation/Qualifications from Frontend (Sub-project 3/5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove `overall_recommendation`/`meets_min_qualifications`/`hireRate`/`meetsMinRate` and their UI from `console-web`'s TypeScript types and views — removed, not replaced with substitute metrics.

**Architecture:** Task 1 fixes the shared types (`data.ts`) and derived-data logic (`roleBreakdown.ts`) that Tasks 2 and 3 depend on. Tasks 2 and 3 then remove the corresponding UI in `Leaderboard.tsx` and `Comparison.tsx`. Because these are TypeScript interfaces consumed across files, `npx tsc -b --noEmit` will genuinely fail between Task 1 and Task 3 (Leaderboard.tsx/Comparison.tsx still reference fields Task 1 just removed from the shared types) — this is expected within this plan and only needs to be green at the end, after Task 3.

**Tech Stack:** TypeScript, React. No automated test runner exists for `console-web/` in this repo (no `*.test.tsx` files, no test script in `package.json`) — verification is `tsc` plus manual dev-server checks.

## Global Constraints

- Remove UI elements outright; do not replace them with substitute metrics (e.g. do not add seniority/education average cards to fill the space left by the removed hire-rate/meets-min cards) — this was explicitly decided with the user during design.
- No backend/Python files are touched in this plan.
- `console-web/src/data/real-data.json` is not regenerated by this plan — it still has the old (pre-sub-project-2) shape locally. This is expected; see each task's testing notes.
